## Featured projects

### 🛒 Glam Cart: Full-Stack Fashion E-commerce Platform
**Stack:** React.js · Node.js · Express · MongoDB · Tailwind CSS

A MERN stack e-commerce application with a customer storefront and a role-protected admin dashboard.

- Multiple payment options: Cash on Delivery, Bank Transfer and PayHere
- Voucher-based checkout with server-side stock validation
- Order-confirmation emails using Nodemailer
- JWT authentication with role-based access control

### 📋 Flowboard: Team Task Management Platform *(in progress, private repository)*
**Stack:** Next.js (App Router) · TypeScript (strict) · Tailwind CSS · Zod · Prisma · PostgreSQL · Auth.js

A production-quality mini Trello/Jira where work is organised as **Workspaces → Boards → Lists → Tasks**.

- Planned MVP: authentication, workspaces with roles (Owner / Admin / Member), drag-and-drop boards, comments, labels, assignees, due dates, priorities and an activity log
- Layered architecture: UI → Server Action → authenticate → validate (Zod) → authorize → Service → Repository → Database
- Engineering workflow: ESLint, Prettier, Husky pre-commit checks and conventional commits
- Planned testing and delivery: Vitest, Playwright, GitHub Actions and Vercel

### 🏥 Hospital Management System: Galle National Hospital *(university group project)*
**Stack:** React.js · Spring Boot · MySQL

A full-stack web application to manage patient records and streamline administrative workflows, built with Agile practices.

- Responsive React interface connected to a Spring Boot REST API
- Secure, optimized relational database schemas in MySQL
